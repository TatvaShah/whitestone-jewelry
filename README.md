# Whitestone Jewelry

Demo site for Whitestone Jewelry Inc., a Mississauga studio for lab grown and natural diamonds. Built by ClaudAura IT Solutions from the premium Next.js starter.

## Commands

- `npm run dev` starts the local site
- `npm run lint` typechecks
- `npm run build` optimizes images and builds
- `node scripts/make-og.mjs` writes `public/og.jpg` after a build

Facts on the page come from the research notes for this demo. Opening hours and the postal code are marked Placeholder where the sources disagree or are missing.
